# Automated Income Tax Preparation & Reminder System

## Overview
Filing income tax is confusing for many people, especially when it comes to
organizing income details, deductions, and remembering important deadlines.
This project aims to simplify that process using automation and cloud
technologies.

## Problem Statement
Many individuals struggle to maintain proper records of their income and
deductions throughout the year. As a result, they often depend on last-minute
manual effort or miss tax filing deadlines due to the lack of reminders and
structured guidance.

## Solution
This project provides an automated system that:
- Collects basic income and deduction details from users
- Calculates an estimated tax amount (for demo and learning purposes)
- Generates a simple tax summary report
- Sends automated reminders before important filing deadlines

## Tech Stack
- Backend: Python (Flask)
- Automation & Workflows: n8n
- Database: SQLite
- DevOps & Deployment: Docker, GitHub Actions
- Cloud Platform: AWS EC2

## Key Features
- Simple and easy-to-use data submission
- Automated workflows with minimal manual effort
- Tax summary generation for better understanding
- Email-based reminder notifications
- Deployed on cloud infrastructure for scalability

## Disclaimer
This project is created for educational and demonstration purposes only.
It does not perform actual government income tax filing and does not store
real or sensitive personal information.
